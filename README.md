## 🌟 معرفی کلی و هدف پروژه

**پرومته (Prometheus)** یک ایجنت هوشمند کاملاً خودمختار بر بستر پیام‌رسان تلگرام است که با ترکیب مدل‌های پیشرفته زبانی (LLM) و مجموعه‌ای گسترده از ابزارهای بومی (Tools / Function Calling)، نیاز به پاسخ‌های متنی صرف و توهم‌آمیز را از بین برده است.

پرومته طوری مهندسی شده که در زمان دریافت پرسش‌های نیازمند داده زنده (قیمت، اخبار، هوا، دانلود موزیک، جستجوی وب، مدیریت گروه، تبدیل صوت به متن و غیره)، به جای حدس زدن پاسخ، ابزارهای تخصصی را صدا زده و نتایج را پس از پردازش، در قالبی خوانا و زیبا به کاربر ارائه دهد.

## 🧠 معماری و نحوه کارکرد ربات (How It Works)

چرخه کاری ربات بر پایه یک خط‌لوله (Pipeline) مدرن و چندلایه استوار است:

### ۱. تفکیک نیت و زنجیره ابزار (Intent Resolution & Dynamic Filtering)
پیام کاربر ابتدا تحلیل شده و نیت‌های مختلف آن استخراج می‌گردد. در صورتی که کاربر چند خواسته مطرح کرده باشد (مثلاً همزمان استعلام قیمت بیت‌کوین، وضعیت هواشناسی تهران و ساعت رسمی)، ربات ابزارهای موردنیاز را شناسایی و به صورت **موازی (Parallel Tool Calling)** فراخوانی می‌کند.

### ۲. سیستم حافظه و ذخیره‌سازی ۳ لایه (3-Tier Storage Architecture)
- **لایه اول (L1 Cache - In-Memory):** کش بسیار سریع در حافظه رم با مدیریت انقضای TTL برای داده‌های لحظه‌ای (مانند نرخ ارز و رمزارز).
- **لایه دوم (Cloudflare Workers KV):** حافظه ابری توزیع‌شده با کلید/مقدار برای نگهداری سشن‌ها، کش بلندمدت‌تر و تنظیمات پویا.
- **لایه سوم (Cloudflare D1 SQL Database):** پایگاه داده رابطه‌ای سرورلس با پشتیبانی از FTS5 (Full-Text Search) جهت ذخیره کامل و ساختاریافته تاریخچه چت‌ها، لاگ‌ها و مدیریت اعضا.

### ۳. ایزولاسیون و حفاظت منحصربه‌فرد فرامین ادمین
ابزارهای حساس (نظیر اجرای کد، دستورات ترمینال، مدیریت عضویت ربات در گروه‌ها و بن سراسری) تحت مکانیزم احراز هویت شناسه عددی ادمین (`ADMIN_ID`) قرار دارند. هیچ کاربری نمی‌تواند با تکنیک‌های جیل‌بریک یا جعل هویت به این قابلیت‌ها دسترسی یابد.

## 📋 پیش‌نیازها و پیش‌شرط‌ها (Prerequisites)

برای اجرای این ربات به موارد زیر نیاز دارید:

1. **پایتون نسخه 3.10 یا بالاتر** (توصیه: Python 3.12)
2. **توکن ربات تلگرام (Telegram Bot Token):** دریافت از [@BotFather](https://t.me/BotFather)
3. **شناسه عددی تلگرام شما (Telegram User ID):** شناسه عددی اکانت تلگرام ادمین (دریافت از طریق [@userinfobot](https://t.me/userinfobot))
4. **کلید هوش مصنوعی (AI API Key):**
   - کلید سازگار با API استاندارد OpenAI (شامل OpenAI, OpenRouter, Groq, 9Router, DeepSeek یا سرور محلی vLLM/Ollama).
5. **پایگاه داده کلودفلر (اختیاری اما برای حافظه ابری پیشنهاد می‌شود):**
   - Cloudflare Account ID & API Token
   - Cloudflare D1 Database UUID
   - Cloudflare KV Namespace ID
   *(در صورت عدم تنظیم کلودفلر، کش L1 محلی و سیستم فایل موقت فعال خواهد بود)*
6. **ابزار FFmpeg (اختیاری جهت دانلود و پردازش صوت و ویدیو):**
   - روی لینوکس: `sudo apt install ffmpeg`
   - روی مک: `brew install ffmpeg`

## ⚙️ راهنمای کامل متغیرهای محیطی (.env)

یک فایل با نام `.env` در ریشه پروژه ایجاد کرده و متغیرهای زیر را بر اساس نیاز خود تنظیم فرمایید:

| متغیر | الزامی؟ | توضیح | نمونه مقدار |
| :--- | :---: | :--- | :--- |
| `TELEGRAM_BOT_TOKEN` | ✅ بله | توکن اختصاصی ربات تلگرام از BotFather | `123456789:ABCdef...` |
| `ADMIN_ID` | ✅ بله | شناسه عددی حساب کاربری ادمین ارشد | `987654321` |
| `ROUTER_BASE_URL` | ✅ بله | آدرس سرور هوش مصنوعی (سازگار با OpenAI V1) | `https://api.openai.com/v1` |
| `ROUTER_API_KEY` | ✅ بله | کلید احراز هویت مدل هوش مصنوعی | `sk-...` |
| `ROUTER_MODEL` | ⚪ اختیاری | نام مدل مورد استفاده (پیش‌فرض: `gpt-4o-mini`) | `gpt-4o-mini` یا `deepseek-chat` |
| `CLOUDFLARE_ACCOUNT_ID` | ⚪ اختیاری | شناسه حساب کلودفلر جهت اتصال به D1/KV | رشته ۳۲ کاراکتری کلودفلر |
| `CLOUDFLARE_API_TOKEN` | ⚪ اختیاری | توکن API کلودفلر با دسترسی D1 و KV | `cfut_...` |
| `CLOUDFLARE_D1_ID` | ⚪ اختیاری | شناسه UUID دیتابیس D1 کلودفلر | `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` |
| `CLOUDFLARE_KV_ID` | ⚪ اختیاری | شناسه فضای نام Workers KV | رشته ۳۲ کاراکتری کلودفلر |
| `TAVILY_API_KEY` | ⚪ اختیاری | کلید موتور جستجوی هوشمند Tavily | `tvly-...` |
| `ALLRATESTODAY_API_KEY` | ⚪ اختیاری | کلید API قیمت لحظه‌ای ارزها و طلا | `art_live_...` |
| `GITHUB_TOKEN` | ⚪ اختیاری | توکن گیت‌هاب جهت رفع محدودیت Rate Limit ابزارهای گیت‌هاب | `ghp_...` |
| `SPOTIFY_CLIENT_ID` | ⚪ اختیاری | شناسه کلاینت اسپاتیفای جهت دریافت کاور آلبوم | رشته ۳۲ کاراکتری |
| `SPOTIFY_CLIENT_SECRET` | ⚪ اختیاری | سکرت کلاینت اسپاتیفای | رشته ۳۲ کاراکتری |

## 🚀 نصب و راه‌اندازی گام‌به‌گام (Step-by-Step Installation)

### ۱. کلون کردن مخزن
```bash
git clone https://github.com/zaryamyn273-crypto/prometheusopenbot.git
cd prometheusopenbot
```

### ۲. ساخت و فعال‌سازی محیط مجازی پایتون
```bash
python3 -m venv venv
# در لینوکس / مک:
source venv/bin/activate
# در ویندوز:
venv\Scripts\activate
```

### ۳. نصب وابستگی‌های پروژه
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### ۴. پیکربندی فایل تنظیمات
```bash
cp .env.example .env
nano .env   # یا با هر ویرایشگر دیگر مقادیر خود را وارد نمایید
```

### ۵. اجرای ربات
```bash
python bot.py
```
ربات بلافاصله متصل شده و پس از ثبت منوی کامندها در تلگرام، آماده دریافت پیام‌ها در چت خصوصی و گروه‌ها خواهد بود.

## ☁️ استقرار در محیط پروداکشن و کلود (Cloud Deployment)

این پروژه به همراه فایل‌های کانفیگ آماده برای پلتفرم‌های ابری (مانند **Railway** و موتورهای بیلد مبتنی بر **Nixpacks / Docker**) ارائه شده است.

### استقرار در Railway:
1. مخزن را به حساب گیت‌هاب خود Fork یا Push کنید.
2. در داشبورد [Railway.app](https://railway.app)، یک پروژه جدید از نوع **GitHub Repo** بسازید و این مخزن را انتخاب کنید.
3. در بخش **Variables**، متغیرهای محیطی شرح داده شده در جدول بالا را اضافه نمایید.
4. پروژه به صورت خودکار از طریق فایل کانفیگ `nixpacks.toml`، نسخه پایتون 3.12 و ابزار `ffmpeg` را نصب کرده و با اجرای `python bot.py` سرویس را بالا می‌آورد.

### اجرای پیوسته در لینوکس با Systemd:
یک سرویس در مسیر `/etc/systemd/system/prometheus.service` بسازید:
```ini
[Unit]
Description=Prometheus Telegram Super Agent
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/path/to/prometheusopenbot
ExecStart=/path/to/prometheusopenbot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
سپس فعال‌سازی:
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now prometheus
```

## 🧰 دسته‌بندی و ماتریکس ابزارها (Tools Matrix)

این دستیار دارای بیش از **۹۰ ابزار ثبت‌شده** در قالب ماژول‌های مستقل است:

1. **📊 ابزارهای مالی و اقتصادی (`src/tools/financial/`):**
   - استعلام زنده قیمت رمزارزها از بایننس و نوبیتکس (`get_price`, `get_crypto_overview`).
   - نرخ لحظه‌ای طلا، مسکوکات (امامی، بهار آزادی، نیم، ربع) و حباب سکه (`get_gold_and_coin_price`).
   - نرخ لحظه‌ای تتر، دلار، یورو، درهم و برابری ارزهای فارکس (`get_dollar_price`, `get_fiat_overview`, `get_global_forex_rates`).

2. **🌐 ابزارهای جستجو، وب و شبکه (`src/tools/web_network/`):**
   - جستجوی وب هوشمند با موتور Tavily AI و موتورهای ترکیبی (`tavily_search`, `web_search`, `deep_search_and_read`).
   - اخبار زنده در حوزه‌های سیاسی، اقتصادی، فناوری و ورزشی (`live_news`).
   - استعلام کالا و قیمت‌ها از دیجی‌کالا (`digikala_search`).
   - ابزارهای شبکه: `ip_lookup`, `dns_lookup`, `ssl_certificate_checker`.
   - پیش‌بینی آب و هوا به همراه جزئیات رطوبت و کیفیت هوا (`get_weather`).

3. **🎵 موتور چندرسانه‌ای و صوت (`src/tools/media/`):**
   - جستجو و دانلود قطعات موسیقی با کیفیت اورجینال ۳۲۰ به‌همراه تگ‌های آی‌دی و کاور (`download_music_track`).
   - دریافت متن ترانه‌ها و فایل لیریکس زمان‌بندی‌شده (`get_song_lyrics`).
   - تبدیل فایل‌های صوتی و وویس به متن توسط هوش مصنوعی Whisper (`transcribe_audio_tool`).
   - تولید بارکدهای دوبعدی QR Code با کیفیت بالا (`generate_qr_code_tool`).
   - انتشار مقالات بلند و متون غنی در بستر Instant View تلگراف (`publish_telegraph_article`).

4. **🔬 محاسبات علمی و ابزارهای عمومی (`src/tools/scientific/`):**
   - ماشین‌حساب پیشرفته ریاضی و عبارات علمی (`calculate_math_expression`).
   - تحلیل‌های آماری (`statistics_summary`).
   - تبدیل زمان، تقویم و ساعت دقیق رسمی (`get_current_datetime_info`).
   - تبدیل واحدهای فیزیکی و تولید انواع هش (`hash_generator`, `unit_converter`).

5. **🛡️ ابزارهای سیستم، امنیت و مدیریت ادمین (`src/tools/admin/` & `src/tools/system/`):**
   - اجرای کدهای پایتون در محیط ایزوله و سندباکس ویژه ادمین (`execute_python_code`).
   - تله‌متری سرور، میزان مصرف رم و سلامت سیستم (`admin_system_diagnostics`).
   - مسدودسازی سراسری یا سکوت کاربران در دیتابیس D1 (`ban_user_tool`, `mute_user_tool`).
   - مدیریت گروه‌ها، گزارش اعضا و خروج اضطراری ربات (`list_joined_groups_tool`, `leave_group_by_admin_tool`).

6. **🐙 ابزارهای جامع گیت‌هاب (`src/tools/github/`):**
   - جستجوی مخازن، ایشوها، کامیت‌ها، انتشارات و تحلیل ریپازیتوری‌های گیت‌هاب.

## 🔒 امنیت، ایزولاسیون و حفاظت از اطلاعات (Security Model)

- **ماسک‌سازی خودکار سکرت‌ها:** هرگونه خروجی ابزارها یا لاگ‌ها از فیلتر Regex و کلیدهای شناخته‌شده عبور کرده و مقادیر حساس با برچسب `[SECRET]` پوشانده می‌شوند تا از افشای توکن‌ها در چت‌ها جلوگیری شود.
- **تفکیک کامل دسترسی چت خصوصی و گروه:** فرامین مدیریتی در چت خصوصی فقط برای شناسه عددی مشخص‌شده در `ADMIN_ID` باز است.
- **جلوگیری از حملات تزریق پرامپت (Prompt Injection & Jailbreak Guard):** منطق ربات در سطح کد پایتون و سیستم پرامپت، در برابر دستکاری نقش و فرامین فریبنده ایمن‌سازی شده است.
