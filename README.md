## ویژگی‌های کلیدی و قابلیت‌های جدید

* 🔍 **موتور سرچ زنده و پرسرعت وب (زیر ۱.۲ ثانیه):**
  - اجرای رقابت همزمان (Speculative Multi-Engine Race) میان Tavily AI، بینگ، داک‌داک‌گو و ویکی‌پدیا.
  - مدارشکن خودکار کوتای تاویلی (Circuit Breaker) برای حذف کامل خطاهای ۴۲۹ و تاخیرهای ناشی از تایم‌اوت.
* 🎙️ **موتور پردازش صوت و بینایی چندحالته (Multimodal Voice & Vision):**
  - تبدیل گفتار به متن (STT) فوق‌سریع با تلفیق مدل‌های هوش بصری/شنیداری پیشرفته؛ بدون وابستگی به سرورهای محلی سنگین.
  - بینایی ماشین با رزولوشن بالا (2048px High-Def) با پشتیبانی همزمان از عکس‌های فشرده تلگرام و اسناد تصویری باکیفیت بدون فشرده‌سازی.
* 🏷️ **موتور پیشرفته تولید و بازسازی بارکدهای آسیب‌دیده (`barcode`):**
  - تولید انواع بارکدهای صنعتی خطی (Code-128, EAN-13, Code-39) و کیوآرکد دوبعدی با بالاترین سطح تصحیح خطا (**Level H با مقاومت ۳۰٪ در برابر آسیب فیزیکی**).
  - **ترمیم جبری بارکدهای خط‌خورده:** کشف و بازسازی ارقام مفقود یا مخدوش با الگوریتم توازن ریاضی Luhn Mod-10 و تولید تصویر سالم جایگزین.
* 🛡️ **حکمرانی زنده و تایید نفوذناپذیر گروه‌ها:**
  - استعلام لحظه‌ای و تمام‌موازی وضعیت گروه‌ها (`list_joined_groups_tool`) شامل تعداد اعضای زنده، سطح اختیارات ربات (ادمین یا کاربر عادی) و لینک‌های معتبر.
  - **گیت امنیتی ۱۰۰٪ سایلنت:** مسدودسازی قطعی گروه‌های ناشناس تا زمان تایید مستقیم فرمانده ارشد در پیوی با دکمه‌های شیشه‌ای تایید/رد.
* ⚡ **استخراج سریع شناسه عددی و هویت کاربر (`whois` / `getid`):**
  - استخراج فوری مشخصات و شناسه عددی کاربران با ریپلای روی پیام با عباراتی چون «آیدی»، «شناسه»، «کیه» یا فوروارد کانال در کمتر از ۱۰ میلی‌ثانیه.
* 💰 **پایش مالی زیر ۵۰ میلی‌ثانیه:**
  - نرخ‌های زنده طلا، سکه، تتر، دلار و ارزهای فیات همراه با گرید رمزارزها از صرافی‌های جهانی و داخلی با کش توزیع‌شده L1 RAM و Cloudflare KV.
* 🔒 **امنیت در سطح سازمانی (Hardened Red/Blue Shield):**
  - سپر ضد جیل‌بریک سه‌لایه با نرمال‌سازی NFKC و حذف کاراکترهای نامرئی Zero-Width.
  - محافظت کامل در برابر SSRF در تک‌تک گام‌های ریدایرکت (Hop-by-Hop Redirect SSRF Guard).
  - سندباکس AST پایتون و پاکسازی خودکار کلیه سکرت‌ها و توکن‌ها با برچسب `[SECRET]`.

## شروع سریع و راه‌اندازی

برای اجرای ربات تنها **۳ متغیر اصلی** در فایل محیطی کافی است (سایر سرویس‌ها دارای Fallback خودکار هستند):

```bash
# ۱. دریافت سورس‌کد
git clone https://github.com/zaryamyn273-crypto/prometheusopenbot.git
cd prometheusopenbot

# ۲. ساخت فایل تنظیمات بر اساس نمونه
cp .env.example .env
# متغیرهای TELEGRAM_BOT_TOKEN ،ADMIN_ID و ROUTER_API_KEY را مقداردهی کنید

# ۳. نصب پیش‌نیازها و اجرا
pip install -r requirements.txt
python bot.py

# یا اجرا با داکر:
docker compose up -d --build
```

> **نکته امنیتی:** هیچ کلید یا توکنی در مخزن عمومی قرار ندارد؛ تمام کلیدها در زمان اجرا به عنوان Environment Variable بارگذاری می‌شوند.

## ماتریس ابزارها (Tools Matrix)

| دسته‌بندی | ابزارهای شاخص | شرح عملکرد |
| :--- | :--- | :--- |
| **چندرسانه‌ای و بارکد** | `generate_barcode_tool`<br>`reconstruct_damaged_barcode_tool`<br>`download_music_track`<br>`transcribe_audio_tool` | تولید بارکدهای خطی و کیوآر ۳۰٪ مقاوم، بازسازی ریاضی بارکدهای خط‌خورده، دریافت موزیک ۳۲۰، تبدیل ویس به متن. |
| **وب و شبکه** | `web_search`<br>`fetch_webpage_content`<br>`check_website_status`<br>`resolve_dns` | جستجوی موازی زیر ۱.۲ ثانیه وب، مطالعه صفحات با پالایش تبلیغات، عیب‌یابی شبکه با گارد SSRF، استعلام رکوردهای DNS. |
| **مالی و بازار** | `get_price`<br>`get_crypto_overview`<br>`get_gold_and_coin_price`<br>`get_fiat_overview` | استعلام لحظه‌ای ارزهای دیجیتال، طلا، سکه و ارزهای جهانی با کش زیر ۵۰ میلی‌ثانیه و فالبک به منابع هم‌عرض. |
| **سیستم و ادمین** | `extract_user_id_tool`<br>`list_joined_groups_tool`<br>`ban_user_tool`<br>`execute_python_code` | استعلام آنی هویت و آیدی تلگرام، مانیتورینگ زنده گروه‌ها، مدیریت دسترسی‌ها و سهمیه‌ها، اجرای امن کد در سندباکس ابری. |
| **اسناد و محاسبات** | `read_document_file`<br>`calculate_math_expression`<br>`convert_units` | خواندن امن فایل‌های PDF، Word و Excel، محاسبات پیچیده ریاضی و تبدیل واحدهای استاندارد بین‌المللی. |

## سیستم امنیت و مقاوم‌سازی چندلایه

1. **گارد SSRF پیشرفته با بررسی گام‌به‌گام ریدایرکت‌ها (`src/utils/net_guard.py`):**
   - استعلام آدرس‌های IP واقعی در هر گام تغییر مسیر HTTP 302/301 برای مقابله با DNS Rebinding.
   - مسدودسازی دسترسی به رنج‌های لوپ‌بک، خصوصی و متادیتای سرویس‌های ابری (`169.254.169.254`).
2. **سپر ضد جیل‌بریک و تزریق پرامپت (`src/core/guard.py`):**
   - نرمال‌سازی کاراکترها (NFKC) و پاکسازی کاراکترهای پنهان Zero-Width.
   - پایش هوشمند عبارات نادیده‌گیری دستورالعمل‌ها، فیلترها و مهندسی اجتماعی با بازدارندگی ۱۰۰٪ در آزمون‌های نفوذ.
   - بلوک مصونیت در پرامپت سیستمی (`IMMUNITY_BLOCK`) که داده‌های کاربر را صرفاً به عنوان دیتای خام و فاقد اختیار تعریف می‌کند.
3. **پاکسازی خودکار سکرت‌ها و کلیدها (`src/core/security.py`):**
   - مانیتورینگ کلیه خروجی‌ها با ریجکس‌های جامع توکن‌های تلگرام، کلیدهای `sk-`، توکن‌های گیت‌هاب و هدرهای احراز هویت.
   - ماسک‌گذاری فوری هرگونه توکن احتمالی با برچسب `[SECRET]`.
4. **سندباکس کدنویسی و ایزوله‌سازی فایل‌ها:**
   - کدهای هوش مصنوعی در سرور اجرا نمی‌شوند و تنها به سندباکس ابری ایزوله E2B فرستاده می‌شوند.
   - ابزار اسناد تنها مجاز به خواندن پسوندهای مشخص سند در پوشه موقت ایزوله است و فایل‌های اجرایی یا حساس مسدود هستند.

## آزمون‌ها و تست‌های نفوذ (Adversarial Suite)

مجموعه تست‌های خودکار پروژه جهت تضمین سلامت و امنیت:

```bash
# اجرای مجموعه تست‌های نفوذ، ضد جیل‌بریک، SSRF و اعتبارسنجی سندباکس:
python tests/test_adversarial.py

# اجرای تست‌های چندبعدی و پایداری عملکرد:
python tests/run_test_battery.py

# تست سیستم بین‌المللی و پشتیبانی از زبان‌ها:
python tests/test_i18n.py

# تست عملکرد سیستم سهمیه‌بندی و نرخ مصرف:
python tests/test_daily_limit.py
```
