## ویژگی‌های کلیدی و قابلیت‌های جدید

* 🧠 **حافظه رم ایزوله ۳۰ پیام برای هر گروه و واکشی مشروط (On-Demand RAM & D1 Context):**
  - بافر مستقل و اختصاصی در حافظه رم (RAM) تا سقف **۳۰ پیام اخیر برای هر گروه به‌صورت کاملاً تفکیک‌شده** و بدون کوچک‌ترین تداخل کانتکست بین گروه‌های مختلف.
  - واکشی هوشمندانه از رم و دیتابیس D1 **فقط و فقط در صورت درخواست صریح کاربر یا ریپلای** روی پیام‌های قبلی؛ پیام‌های مستقیم با کانتکست صفر و بالاترین سرعت ممکن پردازش می‌شوند.
* 🇮🇷 **تضمین ۱۰۰٪ پاسخ به زبان فارسی و حذف خطای عربی:**
  - مهندسی مجدد موتور تشخیص زبان (`detect_lang`) با اولویت مطلق زبان فارسی برای الفبای مشترک.
  - پیشگیری قطعی از پاسخ به زبان عربی در جملات کوتاه و واژگان فارسی روزمره (حتی فاقد حروف گ/چ/پ/ژ).
* 🎯 **اسکوپ پاسخ مستقیم و لحن تیز و خلاصه‌گو (Direct Scope & Sarcastic Persona):**
  - تمرکز مطلق و منحصربه‌فرد بر پاسخ به همان سؤالی که مستقیماً مطرح شده، بدون حاشیه‌پردازی، نصایح اخلاقی یا پرگویی ناخواسته.
  - لحن مسلط، حرفه‌ای، به‌شدت فشرده و خلاصه‌گو همراه با چاشنی طعنه و کنایه ظریف، هوشمندانه و باوقار (Sarcastic & Witty).
* ⚡ **سینک لحظه‌ای بلک‌لیست و فرامین ادمین میان رم و دیتابیس D1:**
  - استعلام و اعمال تغییرات بلادرنگ لیست بن‌ها و دستورات ابدی سیستم با همگام‌سازی فوری مجموعه‌های فوق‌سریع RAM و پایگاه داده ابری Cloudflare D1.
* 🔍 **موتور سرچ زنده و پرسرعت وب (زیر ۱.۲ ثانیه):**
  - اجرای رقابت همزمان (Speculative Multi-Engine Race) میان Tavily AI، بینگ، داک‌داک‌گو و ویکی‌پدیا.
  - مدارشکن خودکار کوتای تاویلی (Circuit Breaker) برای حذف کامل خطاهای ۴۲۹ و تاخیرهای ناشی از تایم‌اوت.
* 🏷️ **تولید و بازسازی جبری بارکدهای آسیب‌دیده (`barcode`):**
  - تولید انواع بارکدهای صنعتی خطی (Code-128, EAN-13, Code-39) و کیوآرکد دوبعدی با بالاترین سطح مقاومت فیزیکی (**Level H با ۳۰٪ تحمل آسیب**).
  - ترمیم جبری ارقام مخدوش یا خط‌خورده با الگوریتم توازن ریاضی Luhn Mod-10 و هوش بصری.
* 🎙️ **موتور صوت و بینایی چندحالته (Multimodal Voice & 2048px HD Vision):**
  - تبدیل گفتار به متن (STT) با مدل‌های چندحالته مدرن برای فایل‌های صوتی و ویس‌های تلگرام بدون نیاز به سرور محلی سنگین.
  - آنالیز تصاویر با وضوح ۲۰۴۸ پیکسل با پشتیبانی کامل از عکس‌های فشرده و فایل‌های اسنادی بدون افت کیفیت.
* 🛡️ **حکمرانی زنده گروه‌ها و گیت امنیتی ۱۰۰٪ سایلنت:**
  - استعلام بلادرنگ وضعیت گروه‌ها (`list_joined_groups_tool`) شامل اعضای زنده و سطح دسترسی ربات.
  - سکوت مطلق در گروه‌های ثبت‌نشده تا زمان تایید ادمین ارشد با دکمه‌های شیشه‌ای تایید/رد در پیوی.
* ⚡ **استخراج سریع شناسه عددی و هویت کاربر (`whois` / `getid`):**
  - استخراج مشخصات و شناسه عددی کاربران با ریپلای روی پیام با عباراتی چون «آیدی»، «شناسه» یا فوروارد کانال در کمتر از ۱۰ میلی‌ثانیه.
* 🔒 **امنیت در سطح سازمانی (Hardened Red/Blue Shield):**
  - دفاع چندلایه در برابر SSRF در تمام گام‌های ریدایرکت (Hop-by-Hop Redirect SSRF Guard).
  - فیلتر ضد جیل‌بریک سه‌لایه با نرمال‌سازی NFKC و حذف کاراکترهای مخفی Zero-Width.
  - سندباکس تحلیل کدهای پایتون (AST Validator) و ماسک‌سازی خودکار کلیه سکرت‌ها و توکن‌ها با برچسب `[SECRET]`.

## شروع سریع و راه‌اندازی

برای اجرای ربات تنها **۳ متغیر اصلی** در فایل محیطی کافی است (سایر سرویس‌ها دارای Fallback خودکار هستند):

```bash
# ۱. دریافت سورس‌کد
git clone https://github.com/zaryamyn273-crypto/prometheusopenbot.git
cd prometheusopenbot

# ۲. ساخت فایل تنظیمات بر اساس نمونه
cp .env.example .env
# متغیرهای TELEGRAM_BOT_TOKEN ،ADMIN_ID و ROUTER_API_KEY را مقداردهی کنید

# ۳. نصب پیش‌نیازها و اجرا
pip install -r requirements.txt
python bot.py

# یا اجرا با داکر:
docker compose up -d --build
```

> **تضمین پاکی مخزن (Zero Secrets):** هیچ‌گونه کلید، توکن یا داده حساسی در سورس‌کد یا تاریخچه گیت قرار ندارد؛ کلیه متغیرها در زمان اجرا به‌صورت Environment Variable بارگذاری می‌شوند.

## سیستم امنیت و مقاوم‌سازی چندلایه

1. **گارد SSRF پیشرفته با بررسی گام‌به‌گام ریدایرکت‌ها (`src/utils/net_guard.py`):**
   - استعلام آدرس‌های IP واقعی در هر گام تغییر مسیر HTTP 302/301 برای مقابله با DNS Rebinding.
   - مسدودسازی دسترسی به رنج‌های لوپ‌بک، خصوصی و متادیتای سرویس‌های ابری (`169.254.169.254`).
2. **سپر ضد جیل‌بریک و تزریق پرامپت (`src/core/guard.py`):**
   - نرمال‌سازی کاراکترها (NFKC) و پاکسازی کاراکترهای پنهان Zero-Width.
   - پایش هوشمند عبارات نادیده‌گیری دستورالعمل‌ها، فیلترها و مهندسی اجتماعی با بازدارندگی ۱۰۰٪ در آزمون‌های نفوذ.
   - بلوک مصونیت در پرامپت سیستمی (`IMMUNITY_BLOCK`) که داده‌های کاربر را صرفاً به عنوان دیتای خام و فاقد اختیار تعریف می‌کند.
3. **پاکسازی خودکار سکرت‌ها و کلیدها (`src/core/security.py`):**
   - مانیتورینگ کلیه خروجی‌ها با ریجکس‌های جامع توکن‌های تلگرام، کلیدهای `sk-`، توکن‌های گیت‌هاب و هدرهای احراز هویت.
   - ماسک‌گذاری فوری هرگونه توکن احتمالی با برچسب `[SECRET]`.
4. **سندباکس کدنویسی و ایزوله‌سازی فایل‌ها:**
   - کدهای هوش مصنوعی در سرور اجرا نمی‌شوند و تنها به سندباکس ابری ایزوله E2B فرستاده می‌شوند.
   - ابزار اسناد تنها مجاز به خواندن پسوندهای مشخص سند در پوشه موقت ایزوله است و فایل‌های اجرایی یا حساس مسدود هستند.

## آزمون‌ها و تست‌های نفوذ (Adversarial Suite)

مجموعه تست‌های خودکار پروژه جهت تضمین سلامت و امنیت:

```bash
# اجرای مجموعه تست‌های نفوذ، ضد جیل‌بریک، SSRF و اعتبارسنجی سندباکس:
python tests/test_adversarial.py

# اجرای آزمون تشخیص آفلاین زبان‌ها (تضمین تفکیک فارسی و عربی):
python tests/test_detect_lang.py

# اجرای تست‌های چندبعدی و پایداری عملکرد:
python tests/run_test_battery.py

# تست سیستم بین‌المللی و پشتیبانی از زبان‌ها:
python tests/test_i18n.py

# تست عملکرد سیستم سهمیه‌بندی و نرخ مصرف:
python tests/test_daily_limit.py
```
