## معرفی

**پرومته** یه ربات تلگرام متن‌بازه که یه مدل زبانی رو به ابزارهای واقعی وصل می‌کنه. ایده‌ش ساده‌ست و همون رو هم درست انجام می‌ده:

- **حدس نزن، برو ببین:** هر چیزی که داده زنده می‌خواد (قیمت، هوا، اخبار، وضعیت سایت) مستقیم از ابزار میاد، نه از حافظه مدل. اگه ابزار جواب نده، ربات می‌گه نمی‌دونم — همین.
- **هر چیزی کلید نمی‌خواد:** فقط توکن تلگرام، آیدی ادمین و یه کلید مدل سازگار با OpenAI لازمه. بقیه (Tavily، Cloudflare، گیت‌هاب، اسپاتیفای، E2B) اختیاری‌ان و بدون اونا هم کار می‌کنه، فقط با fallback رایگان.
- **تو گروه سرش تو کار خودش نیست:** فقط وقتی جواب می‌ده که صداش کنی (ریپلای، منشن، یا اسم «پرومته»). بقیه پیام‌ها رو ساکت آرشیو می‌کنه.
- **کد روی سرور اجرا نمی‌شه:** کدهای نوشته‌شده توسط AI فقط تو سندباکس ابری E2B اجرا می‌شن؛ بدون کلید E2B ابزار اجرای کد غیرفعاله (فال‌بک لوکال عمداً وجود نداره). شل مخرب تحت هیچ شرایطی اجرا نمی‌شه، حتی به دستور ادمین.
- **فقط فارسی نیست:** زبان متن پیام رو خودش تشخیص می‌ده (نه فقط تنظیمات تلگرام) و جواب نهایی AI به همون زبون برمی‌گرده — فارسی، انگلیسی، روسی، عربی، ترکی و...؛ خروجی ابزارها هم در صورت نیاز ترجمه می‌شن.
- **سهمیه روزانه منصفانه:** هر کاربر در همه گروه‌ها روزانه `DAILY_USER_LIMIT` پاسخ کامل AI می‌گیرد (پیش‌فرض ۴۰)؛ ریست خودکار هر ۲۴ ساعت (نیمه‌شب UTC) بدون کرون؛ ادمین نامحدود و می‌تواند سهمیه هر کاربر را جدا کم/زیاد کند (`/setquota`، `/resetquota` یا ریپلای «سهمیه ۱۰۰»). دستور `/limit` سهمیه باقی‌مانده را نشان می‌دهد.
- **ادمین لازم نیست اسلش بزند:** قصد ادمین از متن فارسی/انگلیسی فهمیده و مستقیم اجرا می‌شود («پرومته از گروه X خارج شو»، «leave group X»، «لیست گروه‌ها») — بدون حدس‌زنی، با راستی‌آزمایی زنده.
- **امنیت گروه‌ها:** عضویت جدید با تایید ادمین (دکمه فعال/رد در پیوی)، لیست زنده از تلگرام، حفظ سوابق هنگام خروج، و خروج همیشه تک‌هدفه و راستی‌آزمایی‌شده.

## شروع سریع

فقط **۳ متغیر** برای بالا اومدن لازمه — بقیه اختیاری‌ان:

```bash
git clone https://github.com/zaryamyn273-crypto/prometheusopenbot.git
cd prometheusopenbot
cp .env.example .env   # ست کن: TELEGRAM_BOT_TOKEN ،ADMIN_ID ،ROUTER_API_KEY
pip install -r requirements.txt && python bot.py
# یا با داکر: docker compose up -d --build
```

راهنمای کامل کلیدها (فارسی): [docs/setup/keys.fa.md](docs/setup/keys.fa.md) — انگلیسی: [docs/setup/keys.md](docs/setup/keys.md)
دیپلوی: [Railway](docs/setup/railway.md) • [Docker](docs/setup/docker.md)

## معماری

چرخه کاری ربات بر پایه یک خط‌لوله (Pipeline) مدرن و چندلایه استوار است:

```text
┌─────────────────────────────────────────────────────────────┐
│                      کاربر در تلگرام                        │
└──────────────────────────────┬──────────────────────────────┘
                                │ (متن، صوت، ریپلای، فایل)
                                ▼
┌─────────────────────────────────────────────────────────────┐
│                 Telegram Dispatcher Engine                  │
│        (احراز هویت، کنترل ریت‌لیمیت، آنالیز دسترسی)          │
└──────────────────────────────┬──────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────┐
│                   3-Tier Memory Architecture                │
│  • L1 Cache: رم محلی فوق‌سریع برای کش نرخ‌ها و پاسخ‌ها       │
│  • Cloudflare KV: حافظه کلید/مقدار ابری توزیع‌شده           │
│  • Cloudflare D1: دیتابیس SQL با جستجوی متنی FTS5          │
└──────────────────────────────┬──────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────┐
│             Autonomous LLM Multi-Step Reasoner              │
│     (استدلال چندمرحله‌ای و تولید Function Calls همزمان)      │
└──────────────────────────────┬──────────────────────────────┘
                                │ (Parallel Tool Execution)
                                ▼
┌─────────────────────────────────────────────────────────────┐
│               Tool Matrix (حدود ۹۰ ابزار)                  │
│  • ابزارهای مالی (بایننس، نوبیتکس، طلا، سکه، تتر، فارکس)    │
│  • وب و اخبار (Tavily AI، اسکرپر وب، دیجی‌کالا، آب‌وهوا)      │
│  • مدیا و صوت (دانلود موزیک ۳۲۰، ویسپر STT، QR، تلگراف)    │
│  • مدیریت و سیستم (سندباکس کد پایتون، لاگ، بن سراسری)        │
└──────────────────────────────┬──────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────┐
│               Telegram HTML & Shield Formatter              │
│     (ماسک‌سازی امنیتی [SECRET] و فرمت‌بندی استاندارد پیام)   │
└──────────────────────────────┬──────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────┐
│                     ارسال پاسخ به تلگرام                    │
└─────────────────────────────────────────────────────────────┘
```

- **Tier 0/1 triage:** ساعت، خوش‌وبش و تابلوی قیمت‌ها بدون چرخه AI جواب می‌گیرن (صفر راند اضافه).
- **Lazy loading:** ماژول ابزار فقط وقتی لود می‌شه که لازم باشه؛ ایمپورت ربات ~۹۰ ماژول کمتر و ~۳۰٪ رم کمتر مصرف می‌کنه.
- **حافظه ۳ لایه:** رم محلی → KV ابری → D1 (با fallback خودکار به رم).
- جزئیات: [docs/architecture/overview.md](docs/architecture/overview.md)

## امنیت

- کدهای AI فقط در سندباکس ابری E2B اجرا می‌شن (بدون کلید: غیرفعال، بدون فال‌بک لوکال).
- سکرت‌ها با `[SECRET]` ماسک می‌شن؛ احراز هویت ادمین فقط با شناسه عددی.
- ضد جیل‌بریک سه‌لایه: اسکن قطعی پیام قبل از AI (الگوی override/نقش/ادعای ادمین، فارسی+انگلیسی)، بلوک مصونیت در پرامپت سیستمی (سلسله‌مراتب دستور + تفکیک داده/دستور)، و گیت ابزار ادمین (اسکیمای ابزار ادمین هرگز به کاربر عادی نشان داده نمی‌شود).
- SSRF گارد: واکشی URL فقط به هاست عمومی (بدون لوپ‌بک/خصوصی/متادیتا)؛ فایل‌خوان محدود به `/tmp`؛ خروجی HTML با escape.
- مدل امنیتی کامل + گزارش آسیب‌پذیری: [SECURITY.md](SECURITY.md)
