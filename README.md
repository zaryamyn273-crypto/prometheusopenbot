# پرومته (Prometheus) — ربات هوشمند چندرسانه‌ای، ایجنت‌محور و امن تلگرام

## ویژگی‌های کلیدی و قابلیت‌های جدید

* 🗑️ **حذف دسته‌جمعی و پاک‌سازی هوشمند پیام‌ها (Bulk Message Purge & Clean):**
  - امکان پاک‌سازی سریع و دسته‌جمعی پیام‌های ارسالی ربات با فرامین `/purge <تعداد>`، `/del <تعداد>` یا `/clean <تعداد>`.
  - پشتیبانی کامل از درخواست‌های زبانی طبیعی فرمانده («۱۰ تا پیام آخرت رو پاک کن»، «پیام‌هاتو حذف کن») بدون نیاز به دستور متنی.
  - حذف همگام در تلگرام از طریق API بهینه `delete_messages`، حذف قطعی سوابق از دیتابیس Cloudflare D1 و پاک‌سازی بلادرنگ از حافظه بافر موقت RAM همراه با پیام تأییدیه خودحذف‌شونده (Ephemeral Notice).
* 🚂 **مدیریت مستقیم زیرساخت و ری‌دیپلوی ریلوی (Railway Cloud Infrastructure Manager):**
  - اتصال مستقیم به Railway GraphQL API با احراز هویت امن بر پایه توکن محیطی بدون نشت در سورس‌کد.
  - فرامین و ابزارهای `/railway status`، `/railway redeploy [service]` و `/railway vars` جهت مانیتورینگ سلامت سرویس‌ها (`prometheusopenbot` و `9router`)، بررسی وضعیت استقرار و تریگر ری‌دیپلوی فوری از داخل تلگرام.
  - **ترمینال شل لینوکس ارتقایافته (`/sh`):** ماندگاری دایرکتوری کاری در طول نشست ادمین (`cd`)، تایم‌اوت ۳۵ ثانیه‌ای، محیط احراز هویت‌شده و ارسال خروجی‌های حجیم فراتر از سقف تلگرام به صورت فایل لاگ پیوست (`shell_output.log`).
* 🕵️‍♂️ **موتور عمیق شناسایی هویت و ردپای دیجیتال (Deep OSINT Dossier Engine):**
  - ابزار پیشرفته `osint_person_dossier` برای کاوش و تجمیع اطلاعات عمومی افراد، نام‌های کاربری، ایمیل‌ها و آیدی‌های آنلاین.
  - پویش موازی و همزمان در پلتفرم‌های GitHub، کی‌بیس (Keybase - هویت‌های رمزنگاری‌شده و اثبات PGP)، تلگرام، ردیت، هکرنیوز، گراواتار و جستجوی عمیق لینکدین و رزومه‌ها با ارزیابی سطح افشای ردپای دیجیتال (Footprint Exposure Level).
* 🐙 **کنترل کامل اکانت گیت‌هاب و اتوماسیون پکیجینگ (GitHub Account Automation & Dev Tools):**
  - ساخت مستقیم مخازن جدید عمومی یا خصوصی روی اکانت کاربر (`github_create_repository`).
  - نوشتن و کامیت مستقیم هرگونه فایل به مخزن همراه با پیام کامیت دلخواه (`github_create_or_update_file`).
  - تولید استاندارد فایل ساخت بسته آرچ‌لینوکس (`github_generate_pkgbuild`) منطبق با pacman و AUR.
  - تولید استاندارد فایل ساخت پروژه مدرن C++20 (`github_generate_cmake`) با فلگ‌های سخت‌گیرانه کامپایلر و قوانین نصب.
  - تقویت موتور سرچ گیت‌هاب با ترجمه اصطلاحات فنی فارسی به کلیدواژه‌های بین‌المللی برنامه‌نویسی.
* 🏷️ **بازسازی پیشرفته و عیب‌یابی بارکدهای مخدوش (GS1 & Multi-Wildcard Barcode Solver):**
  - جدول رسمی پیشوندهای کشوری سازمان جهانی GS1 (شناسایی دقیق ۶۲۶ ایران، فرانسه، آلمان، ژاپن و...).
  - حل معادلات چندمجهولی جبری Modulo-10 و Modulo-11 برای بارکدهای دارای چند بخش مخدوش و خط‌خورده (`??`) در فرمت‌های EAN-13، EAN-8، UPC-A و ISBN-10.
  - بازتولید تصویر باکیفیت و اسکن‌پذیر استاندارد صنعتی به همراه گزارش کامل توازن وزنی چک‌سام.
* 🌍 **موتور زمان‌بندی و کرون‌جاب بین‌المللی با هوش تشخیص مناطق زمانی (Timezone-Aware Cron Engine):**
  - زمان‌بندی تسک‌ها، پیام‌های یادآوری و گزارش‌های خودکار بازار با ماندگاری کامل در دیتابیس Cloudflare D1 (مقاوم در برابر ری‌استارت سرور).
  - **تشخیص هوشمندانه منطقه زمانی (Timezone Inference):** شناسایی ساعت و کشور بر اساس زبان کاربر (فارسی ➔ `Asia/Tehran`، انگلیسی ➔ `UTC`، عربی ➔ `Asia/Dubai`، آلمانی ➔ `Europe/Berlin` و...).
  - **استخراج مستقیم ساعت شهرها از متن:** امکان تعیین زمان‌بندی بر اساس افق هر شهر دلخواه («ساعت ۱۴:۰۰ به وقت لندن»، «at 9 am est»، «ساعت ۵ عصر به وقت دبی»).
* 🚪 **گیت تایید صلاحیت گروه‌ها با عدم تایید و عدم خروج خودکار (Strict Group Authorization Gate):**
  - با اضافه شدن ربات به هر گروه، ربات وارد وضعیت تعلیق (`pending`) می‌شود؛ بدون تایید یا خروج خودسرانه، تا زمان تصمیم مستقیم ادمین ارشد در پیوی در سکوت کامل می‌ماند.
* 🛡️ **ایزولاسیون کامل داده‌های گروه‌ها و سپر ضد لیمیت کلودفلر (Zero Cross-Group Collision & Cloudflare Quota Shield):**
  - نگاشت ایزوله نام‌های کاربری به ازای هر چت مجزا (`_CHAT_DISPLAY_NAMES`) جهت پیشگیری قطعی از تداخل هویت کاربران هم‌نام.
  - معماری ثبت دسته‌ای هوشمند با پنجره ۳ ثانیه‌ای (Debounced Write-Behind Coalescer): درج تجمیعی پیام‌ها با **کاهش بیش از ۹۵ درصدی درخواست‌های کلودفلر**.
  - بافر مستقل در حافظه رم تا سقف ۳۰ پیام اخیر برای هر گروه به‌صورت تفکیک‌شده.
* 🇮🇷 **تضمین ۱۰۰٪ پاسخ به زبان فارسی و لحن خلاصه‌گو، مسلط و طعنه‌زننده:**
  - رفع قطعی خطای خروجی عربی در پرامپت‌های فارسی روزمره.
  - تمرکز مطلق بر پاسخ به سوال مستقیم، حذف اضافه‌گویی و پرگویی‌های مرسوم، با چاشنی طنز تلخ و کنایه هوشمندانه (Sarcastic & Witty).
* ☁️ **سندباکس ابری ایزوله E2B (E2B Cloud Code Sandbox):**
  - اجرای کاملاً ایزوله کدهای پایتون و جاوااسکریپت در کانتینرهای کلاد E2B؛ حذف کامل RCE و بار پردازشی روی سرور لوکال.

## شروع سریع و راه‌اندازی

برای اجرای ربات تنها **۳ متغیر اصلی** در فایل محیطی کافی است (سایر سرویس‌ها دارای Fallback خودکار هستند):

```bash
# ۱. دریافت سورس‌کد
git clone https://github.com/zaryamyn273-crypto/prometheusopenbot.git
cd prometheusopenbot

# ۲. ساخت فایل تنظیمات بر اساس نمونه
cp .env.example .env
# متغیرهای TELEGRAM_BOT_TOKEN ،ADMIN_ID و ROUTER_API_KEY را مقداردهی کنید

# ۳. نصب پیش‌نیازها و اجرا
pip install -r requirements.txt
python bot.py

# یا اجرا با داکر:
docker compose up -d --build
```

> **تضمین پاکی مخزن (Zero Secrets):** هیچ‌گونه کلید، توکن یا داده حساسی در سورس‌کد یا تاریخچه گیت قرار ندارد؛ کلیه متغیرها در زمان اجرا به‌صورت Environment Variable بارگذاری می‌شوند.

## ماتریس ابزارها و فرامین ربات

### ۱. دستورات تلگرامی ربات:
* `/del <تعداد>` یا `/purge <تعداد>`: حذف دسته‌جمعی پیام‌های ارسالی ربات یا پیام ریپلای‌شده.
* `/railway [status|redeploy|vars]`: مانیتورینگ سلامت، ری‌دیپلوی سرویس‌ها و متغیرهای پروژه ریلوی.
* `/sh <فرمان لینوکس>`: شل پیشرفته لینوکس روی سرور همراه با حافظه دایرکتوری و ارسال لاگ.
* `/remind <زمان> <متن>` یا `/schedule`: زمان‌بندی تسک یا یادآوری جدید با منطقه زمانی.
* `/schedules`: مشاهده لیست تسک‌های فعال کاربر یا گروه.
* `/cancel_schedule <id>`: لغو تسک با شناسه عددی.
* `/timezone` یا `/tz`: مشاهده یا تنظیم منطقه زمانی محلی.
* `/whois` یا «آیدی»: استخراج مشخصات و شناسه عددی کاربر یا کانال.
* `/admin`: پنل شیشه‌ای مدیریت سیستم برای ادمین ارشد.
* `/ban` و `/unban`: مسدودسازی یا آزادسازی کاربر بر اساس آیدی عددی، یوزرنیم یا نام.

### ۲. ابزارهای خودمختار ایجنت (Agent Tools):
* `purge_chat_messages_tool`: حذف دسته‌جمعی پیام‌های ربات در چت با پیام طبیعی ادمین.
* `railway_status_tool` و `railway_redeploy_tool`: مانیتورینگ و ری‌دیپلوی کانتینرهای ریلوی.
* `osint_person_dossier`: استخراج ردپای دیجیتال، اکانت‌های کاربری و پرونده هویتی OSINT.
* `github_create_repository`: ساخت مخزن جدید در گیت‌هاب.
* `github_create_or_update_file`: کامیت و ذخیره مستقیم فایل در مخزن.
* `github_generate_pkgbuild`: تولید فایل بسته‌بندی آرچ‌لینوکس و AUR.
* `github_generate_cmake`: تولید اسکریپت بیلد مدرن CMakeLists.txt.
* `reconstruct_damaged_barcode_tool`: بازسازی جبری بارکدهای ناقص با استعلام مبدأ کشوری GS1.
* `schedule_task_tool` و `set_user_timezone_tool`: موتور زمان‌بندی بین‌المللی تسک‌ها.
* `download_music_track` و `get_song_lyrics`: دانلود استودیویی موزیک و همگام‌سازی لیریکس تایم‌دار.

## سیستم امنیت و مقاوم‌سازی چندلایه

1. **Hop-by-Hop Redirect SSRF Guard:** بررسی آدرس IP در هر مرحله از دنبال کردن تغییر مسیر (HTTP Redirect) برای مهار کامل آدرس‌های لوکال (`127.0.0.1`, `10.0.0.0/8`, `169.254.169.254` و DNS Rebinding).
2. **Deterministic Anti-Jailbreak Filter:** پیش‌فیلتر بدون هزینه قبل از مصرف توکن برای شناسایی الگوهای حملات نقض دستورالعمل‌ها، مهندسی پرامپت و تظاهر به شخصیت‌های دیگر.
3. **AST-Based Python Sandbox:** تفکیک و اعتبارسنجی درخت نحو انتزاعی در کدهای پایتون برای جلوگیری از فراخوانی توابع خطرناک سیستم‌عامل (`os`, `sys`, `eval`, `exec`).
4. **Automatic Secret Sanitizer:** ماسک‌سازی خودکار توکن‌های تلگرام، کلیدهای OpenAI/Cloudflare/E2B/Railway در خروجی‌های شل و لاگ‌ها با برچسب `[SECRET]`.
5. **Strict Group Authorization Gate:** مسدودسازی قطعی هرگونه پاسخ‌دهی در گروه‌های ثبت‌نشده با عدم خروج یا تایید خودکار تا زمان اخذ تایید مستقیم ادمین.

## آزمون‌ها و تست‌های نفوذ (Adversarial Suite)

مجموعه تست‌های خودکار پروژه جهت تضمین سلامت کدها و امنیت:

```bash
# اجرای تمامی تست‌های ایزولاسیون دیتابیس و سپر کلودفلر
python -m tests.test_database_isolation

# اجرای تست‌های سیستم کرون‌جاب بین‌المللی و مناطق زمانی
python -m tests.test_scheduler

# اجرای تست‌های نفوذ ضدحملات (Red/Blue Security Audit)
python -m tests.test_adversarial

# اجرای تست‌های تضمین ۱۰۰٪ زبان فارسی
python -m tests.test_detect_lang
```
