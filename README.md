## 🌟 معرفی کلی و هدف پروژه

**پرومته (Prometheus)** یک ایجنت هوشمند کاملاً خودمختار بر بستر پیام‌رسان تلگرام است که با ترکیب مدل‌های پیشرفته زبانی (LLM) و مجموعه‌ای گسترده از ابزارهای بومی (Tools / Function Calling)، نیاز به پاسخ‌های متنی صرف و توهم‌آمیز را از بین برده است.

پرومته طوری مهندسی شده که در زمان دریافت پرسش‌های نیازمند داده زنده (قیمت، اخبار، هوا، دانلود موزیک، جستجوی وب، مدیریت گروه، تبدیل صوت به متن و غیره)، به جای حدس زدن پاسخ، ابزارهای تخصصی را صدا زده و نتایج را پس از پردازش، در قالبی خوانا و زیبا به کاربر ارائه دهد.

## 🧠 معماری و نحوه کارکرد ربات (How It Works)

چرخه کاری ربات بر پایه یک خط‌لوله (Pipeline) مدرن و چندلایه استوار است:

```text
┌─────────────────────────────────────────────────────────────┐
│                      کاربر در تلگرام                        │
└──────────────────────────────┬──────────────────────────────┘
                               │ (متن، صوت، ریپلای، فایل)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                 Telegram Dispatcher Engine                  │
│        (احراز هویت، کنترل ریت‌لیمیت، آنالیز دسترسی)          │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                   3-Tier Memory Architecture                │
│  • L1 Cache: رم محلی فوق‌سریع برای کش نرخ‌ها و پاسخ‌ها       │
│  • Cloudflare KV: حافظه کلید/مقدار ابری توزیع‌شده           │
│  • Cloudflare D1: دیتابیس SQL با جستجوی متنی FTS5          │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│             Autonomous LLM Multi-Step Reasoner              │
│     (استدلال چندمرحله‌ای و تولید Function Calls همزمان)      │
└──────────────────────────────┬──────────────────────────────┘
                               │ (Parallel Tool Execution)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│               Tool Matrix (بیش از ۹۰ ابزار)                 │
│  • ابزارهای مالی (بایننس، نوبیتکس، طلا، سکه، تتر، فارکس)    │
│  • وب و اخبار (Tavily AI، اسکرپر وب، دیجی‌کالا، آب‌وهوا)      │
│  • مدیا و صوت (دانلود موزیک ۳۲۰، ویسپر STT، QR، تلگراف)    │
│  • مدیریت و سیستم (سندباکس کد پایتون، لاگ، بن سراسری)        │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│               Telegram HTML & Shield Formatter              │
│     (ماسک‌سازی امنیتی [SECRET] و فرمت‌بندی استاندارد پیام)   │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                     ارسال پاسخ به تلگرام                    │
└─────────────────────────────────────────────────────────────┘
```

### ۱. تفکیک نیت و اجرای موازی ابزارها (Parallel Tool Calling)
پیام کاربر ابتدا تحلیل شده و نیت‌های مختلف آن استخراج می‌گردد. در صورتی که کاربر چند خواسته مطرح کرده باشد (مثلاً همزمان استعلام قیمت بیت‌کوین، وضعیت هواشناسی تهران و ساعت رسمی)، ربات ابزارهای موردنیاز را شناسایی و به صورت موازی فراخوانی می‌کند.

### ۲. سیستم حافظه و ذخیره‌سازی ۳ لایه (3-Tier Storage)
- **لایه اول (L1 In-Memory Cache):** کش بسیار سریع در حافظه رم با مدیریت انقضای TTL برای داده‌های لحظه‌ای (مانند نرخ ارز و رمزارز).
- **لایه دوم (Cloudflare Workers KV):** حافظه ابری توزیع‌شده با کلید/مقدار برای نگهداری سشن‌ها، کش بلندمدت‌تر و تنظیمات پویا.
- **لایه سوم (Cloudflare D1 SQL Database):** پایگاه داده رابطه‌ای سرورلس با پشتیبانی از FTS5 (Full-Text Search) جهت ذخیره کامل و ساختاریافته تاریخچه چت‌ها، لاگ‌ها و مدیریت اعضا.

### ۳. ایزولاسیون و حفاظت فرامین ادمین
ابزارهای حساس (نظیر اجرای کد پایتون، دستورات ترمینال، مدیریت عضویت ربات در گروه‌ها و بن سراسری) تحت مکانیزم احراز هویت شناسه عددی ادمین (`ADMIN_ID`) قرار دارند. هیچ کاربری نمی‌تواند با تکنیک‌های پرامپت اینجکشن یا جعل هویت به این قابلیت‌ها دسترسی یابد.

## 🔑 راهنمای جامع تهیه کلیدها و پیش‌نیازها (Where & How to Get Keys)

برای اینکه ربات با تمامی قابلیت‌های خود شروع به کار کند، به مجموعه‌ای از کلیدها و شناسه‌ها نیاز دارید. برخی از این کلیدها **الزامی** (برای بالا آمدن اولیه ربات) و برخی **اختیاری** (برای فعال‌سازی ابزارهای جانبی) هستند.

### ۱. توکن ربات تلگرام (TELEGRAM_BOT_TOKEN) — [الزامی 🔴]
- **کاربرد:** شناسه اصلی ربات تلگرام برای اتصال به سرورهای تلگرام و دریافت/ارسال پیام‌ها.
- **نحوه تهیه:**
  1. در تلگرام وارد ربات رسمی [@BotFather](https://t.me/BotFather) شوید.
  2. دستور `/newbot` را ارسال کنید.
  3. یک نام نمایشی (Name) و سپس یک نام کاربری (Username که به `bot` ختم شود) انتخاب نمایید.
  4. بات‌فادر به شما یک توکن شبیه به این می‌دهد: `1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ`
  5. برای گروه‌ها، دستور `/setprivacy` را در BotFather زده، ربات خود را انتخاب کرده و آن را `Disable` کنید تا ربات بتواند پیام‌های گروه را جهت پاسخ‌دهی پردازش کند.

### ۲. شناسه عددی ادمین (ADMIN_ID) — [الزامی 🔴]
- **کاربرد:** تعیین هویت مالک و فرمانده ارشد ربات جهت دسترسی به پنل مدیریت، ابزار اجرای کد پایتون، مسدودسازی کاربران و مدیریت گروه‌ها.
- **نحوه تهیه:**
  1. در تلگرام وارد ربات [@userinfobot](https://t.me/userinfobot) یا [@JsonDumpBot](https://t.me/JsonDumpBot) شوید.
  2. پیام استارت را بزنید تا شناسه عددی خود را (یک عدد چند رقمی مثل `123456789`) دریافت کنید.
  3. این عدد را در متغیر `ADMIN_ID` قرار دهید.

### ۳. کلید و آدرس هوش مصنوعی (ROUTER_API_KEY & ROUTER_BASE_URL) — [الزامی 🔴]
- **کاربرد:** مغز متفکر ربات برای استدلال، درک نیت کاربر و فراخوانی ابزارها (Function Calling). این سیستم از استاندارد رسمی **OpenAI API** پشتیبانی می‌کند، بنابراین می‌توانید از هر ارائه‌دهنده‌ای استفاده نمایید:
- **گزینه‌های پیشنهادی برای تهیه:**
  - **OpenAI رسمی:**
    - ورود به [platform.openai.com](https://platform.openai.com/api-keys)
    - ساخت کلید جدید (`sk-...`)
    - تنظیم `ROUTER_BASE_URL=https://api.openai.com/v1` و `ROUTER_MODEL=gpt-4o-mini`
  - **OpenRouter (پیشنهادی برای دسترسی به ده‌ها مدل متنوع):**
    - ورود به [openrouter.ai](https://openrouter.ai/keys)
    - ساخت API Key
    - تنظیم `ROUTER_BASE_URL=https://openrouter.ai/api/v1` و انتخاب مدل دلخواه (مانند `google/gemini-flash-1.5` یا `openai/gpt-4o-mini`)
  - **DeepSeek:**
    - ورود به [platform.deepseek.com](https://platform.deepseek.com/api_keys)
    - ساخت کلید و تنظیم `ROUTER_BASE_URL=https://api.deepseek.com/v1` و `ROUTER_MODEL=deepseek-chat`
  - **Groq (سرعت فوق‌العاده بالا):**
    - ورود به [console.groq.com](https://console.groq.com/keys)
    - ساخت کلید رایگان و تنظیم `ROUTER_BASE_URL=https://api.groq.com/openai/v1` و `ROUTER_MODEL=llama-3.3-70b-versatile`

### ۴. حساب و دیتابیس ابری کلودفلر (Cloudflare D1 & KV) — [پیشنهادی/اختیاری 🟡]
- **کاربرد:** نگهداری دائمی تاریخچه گفتگوها، جستجوی بلادرنگ پیام‌های قبلی گروه، لیست کاربران مسدودشده و کش توزیع‌شده ابری. در صورت عدم تنظیم، ربات روی حافظه رم (L1) به کار خود ادامه می‌دهد.
- **نحوه تهیه رایگان:**
  1. یک حساب در [cloudflare.com](https://cloudflare.com) ایجاد کنید.
  2. **Cloudflare Account ID:** در داشبورد کلودفلر، روی یکی از صفحات Workers & D1 کلیک کنید؛ در ستون سمت راست آیدی اکانت (رشته ۳۲ کاراکتری) را بردارید.
  3. **Cloudflare API Token:** به بخش *My Profile > API Tokens > Create Token* رفته، تمپلیت *Edit Cloudflare Workers* را انتخاب و توکن دسترسی (`cfut_...`) دریافت کنید.
  4. **ساخت پایگاه داده D1:**
     - در داشبورد به بخش *Workers & Pages > D1 SQL Database* بروید و یک دیتابیس بسازید (مثلاً `prometheus-db`).
     - شناسه Database UUID را کپی و در `CLOUDFLARE_D1_ID` قرار دهید.
  5. **ساخت فضای نام KV:**
     - در داشبورد به بخش *Workers & Pages > KV* رفته و یک Namespace بسازید (مثلاً `prometheus-kv`).
     - شناسه Namespace ID را کپی و در `CLOUDFLARE_KV_ID` قرار دهید.

### ۵. کلید سرچ زنده وب Tavily AI (TAVILY_API_KEY) — [اختیاری ⚪]
- **کاربرد:** موتور جستجوی اختصاصی و فوق‌سریع هوش مصنوعی جهت دریافت اخبار لحظه‌ای، مقایسه نسخه‌ها و رویدادهای زنده روز دنیا بدون توهم.
- **نحوه تهیه رایگان:**
  1. به سایت [tavily.com](https://tavily.com) بروید.
  2. ثبت نام کنید (طرح رایگان ماهانه ۱۰۰۰ سرچ بدون نیاز به کارت اعتباری ارائه می‌دهد).
  3. کلید API خود را که با `tvly-` شروع می‌شود کپی کرده و در `TAVILY_API_KEY` قرار دهید.

### ۶. کلید نرخ‌های زنده ارزی و طلا AllRatesToday (ALLRATESTODAY_API_KEY) — [اختیاری ⚪]
- **کاربرد:** واکشی لحظه‌ای نرخ ارزهای فیات (دلار، یورو، درهم و...) و قیمت طلا و سکه بازار ایران به صورت مستقیم.
- **نحوه تهیه:**
  1. مراجعه به وب‌سایت [allratestoday.com](https://allratestoday.com).
  2. ثبت نام و دریافت کلید دسترسی `art_live_...`.
  *(در صورت نبود این کلید، ربات به صورت خودکار از اسکرپرهای زنده وب و منابع جایگزین پشتیبان استفاده خواهد کرد).*

### ۷. توکن دسترسی گیت‌هاب (GITHUB_TOKEN) — [اختیاری ⚪]
- **کاربرد:** افزایش سقف محدودیت درخواست (Rate Limit) برای ابزارهای ۱۲ گانه گیت‌هاب (جستجوی سورس‌کد، کامیت‌ها، ایشوها و انتشارات).
- **نحوه تهیه رایگان:**
  1. وارد حساب گیت‌هاب خود شوید و به [github.com/settings/tokens](https://github.com/settings/tokens) بروید.
  2. روی *Generate new token (classic)* کلیک کنید.
  3. دسترسی `public_repo` یا دسترسی‌های عمومی را تیک زده و توکن تولیدشده (`ghp_...`) را در متغیر `GITHUB_TOKEN` قرار دهید.

### ۸. کلیدهای اسپاتیفای (SPOTIFY_CLIENT_ID & SPOTIFY_CLIENT_SECRET) — [اختیاری ⚪]
- **کاربرد:** دریافت کاور رسمی با کیفیت بالا و متادیتای دقیق قطعات موسیقی خارجی در زمان دانلود موزیک.
- **نحوه تهیه رایگان:**
  1. ورود به [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard).
  2. ساخت یک برنامه ساده (Create App) و کپی کردن `Client ID` و `Client Secret`.
  *(در صورت نبود این مقادیر، ربات از موتور iTunes API و متادیتای پیش‌فرض استفاده می‌کند).*

## 🚀 نصب و راه‌اندازی گام‌به‌گام (Step-by-Step Installation)

### ۱. دریافت سورس‌کد پروژه
```bash
git clone https://github.com/zaryamyn273-crypto/prometheusopenbot.git
cd prometheusopenbot
```

### ۲. ساخت و فعال‌سازی محیط ایزوله پایتون
```bash
python3 -m venv venv
# در لینوکس / مک:
source venv/bin/activate
# در ویندوز:
venv\Scripts\activate
```

### ۳. نصب بسته‌های پیش‌نیاز
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### ۴. ایجاد و تکمیل فایل کانفیگ
```bash
cp .env.example .env
nano .env   # مقادیر کلیدهای دریافت شده را در این فایل قرار دهید
```

### ۵. اجرای ربات
```bash
python bot.py
```
ربات پس از اتصال موفق به تلگرام، لیست کامندها را ست کرده و در کنسول پیام آماده‌باش چاپ می‌کند.

## ☁️ استقرار در محیط پروداکشن و کلود (Cloud Deployment)

### استقرار در Railway:
1. این مخزن را در حساب گیت‌هاب خود Fork یا Push کنید.
2. وارد داشبورد [Railway.app](https://railway.app) شده و روی **New Project > Deploy from GitHub repo** کلیک کنید.
3. مخزن خود را انتخاب کنید.
4. در تب **Variables**، متغیرهای `.env` را اضافه کنید.
5. ریلوِی به لطف فایل‌های `nixpacks.toml` و `railway.json` موجود در پروژه، محیط پایتون 3.12 و ابزار `ffmpeg` را خودکار کانفیگ و پروژه را ران می‌کند.

### اجرای در لینوکس با Systemd:
یک سرویس در مسیر `/etc/systemd/system/prometheus.service` بسازید:
```ini
[Unit]
Description=Prometheus Telegram Super Agent
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/path/to/prometheusopenbot
ExecStart=/path/to/prometheusopenbot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
سپس سرویس را فعال و استارت کنید:
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now prometheus
```

   - نرخ لحظه‌ای طلا، مسکوکات (امامی، بهار آزادی، نیم، ربع) و حباب سکه (`get_gold_and_coin_price`).
   - نرخ لحظه‌ای تتر، دلار، یورو، درهم و برابری ارزهای فارکس (`get_dollar_price`, `get_fiat_overview`, `get_global_forex_rates`).

2. **🌐 ابزارهای جستجو، وب و شبکه (`src/tools/web_network/`):**
   - جستجوی وب هوشمند با موتور Tavily AI و موتورهای ترکیبی (`tavily_search`, `web_search`, `deep_search_and_read`).
   - اخبار زنده در حوزه‌های سیاسی، اقتصادی، فناوری و ورزشی (`live_news`).
   - استعلام کالا و قیمت‌ها از دیجی‌کالا (`digikala_search`).
   - ابزارهای شبکه: `ip_lookup`, `dns_lookup`, `ssl_certificate_checker`.
   - پیش‌بینی آب و هوا به همراه جزئیات رطوبت و کیفیت هوا (`get_weather`).

3. **🎵 موتور چندرسانه‌ای و صوت (`src/tools/media/`):**
   - جستجو و دانلود قطعات موسیقی با کیفیت اورجینال ۳۲۰ به‌همراه تگ‌های آی‌دی و کاور (`download_music_track`).
   - دریافت متن ترانه‌ها و فایل لیریکس زمان‌بندی‌شده (`get_song_lyrics`).
   - تبدیل فایل‌های صوتی و وویس به متن توسط هوش مصنوعی Whisper (`transcribe_audio_tool`).
   - تولید بارکدهای دوبعدی QR Code با کیفیت بالا (`generate_qr_code_tool`).
   - انتشار مقالات بلند و متون غنی در بستر Instant View تلگراف (`publish_telegraph_article`).

4. **🔬 محاسبات علمی و ابزارهای عمومی (`src/tools/scientific/`):**
   - ماشین‌حساب پیشرفته ریاضی و عبارات علمی (`calculate_math_expression`).
   - تحلیل‌های آماری (`statistics_summary`).
   - تبدیل زمان، تقویم و ساعت دقیق رسمی (`get_current_datetime_info`).
   - تبدیل واحدهای فیزیکی و تولید انواع هش (`hash_generator`, `unit_converter`).

5. **🛡️ ابزارهای سیستم، امنیت و مدیریت ادمین (`src/tools/admin/` & `src/tools/system/`):**
   - اجرای کدهای پایتون در محیط ایزوله و سندباکس ویژه ادمین (`execute_python_code`).
   - تله‌متری سرور، میزان مصرف رم و سلامت سیستم (`admin_system_diagnostics`).

## 🔒 امنیت، ایزولاسیون و حفاظت از اطلاعات (Security Model)

- **ماسک‌سازی خودکار سکرت‌ها:** هرگونه خروجی ابزارها یا لاگ‌ها از فیلتر Regex و کلیدهای شناخته‌شده عبور کرده و مقادیر حساس با برچسب `[SECRET]` پوشانده می‌شوند تا از افشای توکن‌ها در چت‌ها جلوگیری شود.
