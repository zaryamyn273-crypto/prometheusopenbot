# ⚡ Prometheus Super-Agent Pro v5.0 Ultimate

**پرومته سوپر ایجنت (Prometheus Super-Agent Pro)**: سریع‌ترین، مقتدرترین و پیشرفته‌ترین دستیار و ایجنت خودمختار هوش مصنوعی تلگرام، مبتنی بر معماری چندلایه کش و ذخیره‌سازی ابری کلودفلر، پردازش چندوجهی تصویر و صوت، و مجهز به بیش از **۴۳ ابزار تخصصی و فوق‌پیشرفته**.

---

## 🌟 قابلیت‌ها و ماژول‌های کلیدی (Key Modules)

### 🧠 ۱. هسته هوش مصنوعی خودمختار (Autonomous Agent Engine)
- **پشتیبانی از مدل Good و روتر پرسرعت** با زمان پاسخ‌دهی زیرمیلی‌ثانیه‌ای و حداقل تأخیر.
- **انتخاب تهاجمی ابزارها (Zero-Hallucination Matrix)**: مدل در برابر سوالات نیازمند داده‌های لحظه‌ای، فوراً ابزار مرتبط را صدا می‌زند.
- **موازی‌سازی چند ابزار (Parallel Tool Calling)**: اجرای همزمان چندین تسک در یک نوبت.
- **حافظه ۵۰,۰۰۰ توکنی کوتاه‌مدت و موقت به‌ازای هر گروه/چت (Rolling Window ایزوله)** و اتصال نامحدود به دیتابیس توزیع‌شده Cloudflare D1.

### 📊 ۲. ماتریکس مالی و اقتصادی (Financial Matrix)
- **رمزارزها (Multi-Exchange Crypto Aggregator)**: قیمت زنده و اردر بوک بایننس، نوبیتکس، کوین‌گکو و وضعیت شبکه تون.
- **طلا، سکه و حباب**: نرخ زنده گرم ۱۸ عیار، آبشده، انس طلا، سکه امامی، نیم، ربع و حباب سکه.
- **ارزهای فیات**: نرخ تتر، دلار، یورو، درهم و پوند در بازار آزاد.
- **همگام‌ساز خودکار ۵ دقیقه‌ای پس‌زمینه (5-Min Auto-Syncer)** جهت پاسخ‌دهی زیرمیلی‌ثانیه‌ای.

### 🌐 ۳. موتور جستجو، وب و شبکه (Web & Network Suite)
- **جستجوی وب چندموتوره (DuckDuckGo, Brave, Google Scraper)**.
- **اخبار زنده و فوری (Live News Feed)** در دسته‌بندی‌های سیاسی، اقتصادی، تکنولوژی و ورزشی.
- **اسکرپر و خلاصه ساز صفحات وب (Deep Web Content Extractor)**.
- **هواشناسی جامع جهانی و ایران** با جزئیات دما، حس واقعی، رطوبت، باد و آلودگی.
- **ابزارهای پیشرفته شبکه**: IP Lookup، DNS Resolution و SSL Certificate Checker.

### 🎵 ۴. هاب چندرسانه‌ای، صدا و رونویسی (Media & Audio Engine)
- **دانلود و پخش مستقیم موزیک (320kbps Original HQ)** برای ترانه‌های ایرانی و بین‌المللی با فرمت صوتی تلگرام.
- **تبدیل وویس و صوت به متن (Speech-to-Text Transcription)** مبتنی بر مدل پیشرفته ویسپر.
- **انتشار مقالات بدون محدودیت در تلگراف (Telegraph Publisher)**.
- **تولیدکننده کدهای QR با کیفیت بالا** و جستجوی متن آهنگ‌ها (Lyrics).

### 🛡️ ۵. امنیت، مدیریت گروه و ادمین (Security & Governance)
- **نگهبان عضویت گروه (Group Membership Guardian)**: لفت خودکار از گروه‌هایی که توسط ادمین ارشد افزوده نشده‌اند.
- **فرمان حذف با ریپلای (`/del` / «حذف» / «پاکش کن»)** برای ادمین و مدیران گروه.
- **سیستم بن/آن‌بن دائمی در دیتابیس D1** با مصونیت مطلق ادمین ارشد (`ADMIN_ID`).
- **اجرای ایزوله کدهای پایتون در Sandbox ایمن**.

### ☁️ ۶. معماری ۳ لایه ذخیره‌سازی ابری کلودفلر (Multi-Tier Storage)
1. **لایه‌ی اول (L1 Cache)**: کش فوق‌سریع درون حافظه با انقضای خودکار TTL.
2. **لایه‌ی دوم (Cloudflare Workers KV)**: حافظه ابری توزیع‌شده با کلید/مقدار برای نگهداری داده‌ها و کش نرخ‌ها.
3. **لایه‌ی سوم (Cloudflare D1 SQL Database)**: دیتابیس سرورلس با جداسازی کامل و سوابق طولانی‌مدت گفتگوها به تفکیک گروه و چت.

## 📂 ساختار پوشه‌بندی ماژولار (Folder Structure)

```
prometheuspro/
├── bot.py                               # فایل اصلی راه‌اندازی و دیسپچر تلگرام
├── requirements.txt                     # پکیج‌های پایتون مورد نیاز
├── test_master.py                       # سوئیت تست و آدیت جامع سیستم
└── src/
    ├── core/
    │   ├── config.py                    # تنظیمات، پرامپت سیستمی و متغیرها
    │   ├── database.py                  # موتور ۳ لایه دیتابیس و کش کلودفلر (D1 + KV + L1)
    │   └── ai_service.py                # مغز متفکر هوش مصنوعی و حلقه استدلال چندمرحله‌ای
    ├── tools/
    │   ├── registry.py                  # رجیستری ابزارها و تولید خودکار OpenAPI Schema
    │   ├── financial/                   # ابزارهای مالی، کریپتو، طلا و فیات
    │   ├── web_network/                 # جستجو، اخبار، هواشناسی و شبکه
    │   ├── scientific/                  # محاسبات، تبدیل واحدها، تایم و کدگذاری
    │   ├── media/                       # موزیک، ویسپر (صدا به متن)، تلگراف و QR
    │   ├── system/                      # سندباکس پایتون، شل و بن/آن‌بن
    │   ├── github/                      # جستجو و تحلیل ریپازیتوری‌های گیت‌هاب
    │   ├── security/                    # جستجوی وب تاریک و امنیت
    │   ├── files/                       # خواندن و پارس اسناد متنی و PDF
    │   └── database/                    # ابزارهای عامل جهت دسترسی مستقیم به D1 و KV
    ├── ui/
    │   └── admin_panel.py               # کیبوردهای شیشه‌ای، پنل ادمین و ابزارها
    └── utils/
        └── telegram_formatter.py        # پارسر ضدخطای Markdown به HTML و باکس بازشونده تلگرام
```

## 🚀 نحوه راه‌اندازی (Quick Start)

### ۱. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### ۲. اجرای ربات
```bash
python bot.py
```

### ۳. اجرای تست‌های یکپارچگی (System Audit)
```bash
python test_master.py
```
