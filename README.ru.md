## Обзор

**Прометей** — open-source Telegram-бот, который подключает языковую модель к реальным инструментам. Идея простая, и он просто её выполняет:

- **Не гадай — проверь:** всё, чему нужны живые данные (цены, погода, новости, статус сайтов), берётся напрямую из инструментов, а не из памяти модели. Если инструмент недоступен, бот так и говорит. Всё.
- **Ключ нужен не для всего:** обязательны только токен Telegram, ID админа и один OpenAI-совместимый ключ модели. Остальное (Tavily, Cloudflare, GitHub, Spotify, E2B) опционально — без них тоже работает, просто на бесплатных запасных вариантах.
- **В группах не лезет без спроса:** отвечает только при обращении (ответ на сообщение, упоминание или слово «Прометей»). Остальное тихо архивируется.
- **На сервере код не выполняется:** написанный ИИ код выполняется только в облачной песочнице E2B; без ключа инструмент отключён (локального запуска нет по дизайну). Деструктивный shell не выполняется никогда, даже по приказу админа.
- **Не только персидский:** язык определяется по тексту сообщения (а не только по настройкам клиента) — персидский, английский, русский, арабский, турецкий...; выводы инструментов при необходимости переводятся.
- **Честная дневная квота:** каждый пользователь получает `DAILY_USER_LIMIT` (по умолчанию 40) полных ИИ-ответов в сутки во всех чатах; автосброс каждые 24 часа (00:00 UTC) без cron; админ — безлимит и может менять квоту любого (`/setquota`, `/resetquota`). Команда `/limit` показывает остаток.
- **Админу не нужен слеш:** поручения на естественном языке выполняются напрямую («leave group X», список групп, «set quota for X to 100»...) — без угадывания, с живой проверкой.
- **Безопасность групп:** вход — только с одобрения админа (кнопки в ЛС), живой список из Telegram, история сохраняется при выходе, выход — всегда точечный и проверенный.
- **Массовое удаление сообщений (`/purge`, `/del`):** атомарная очистка сообщений бота по команде или естественной фразе («удали 10 последних сообщений») синхронно в Telegram, Cloudflare D1 и оперативной памяти.
- **Управление инфраструктурой Railway (`/railway`):** проверка статуса сервисов, просмотр логов и немедленный редеплой контейнеров без хранения ключей в репозитории.
- **Глубокий OSINT (`osint_person_dossier`):** параллельный сбор цифрового следа и досье по GitHub, Keybase, Telegram, Reddit, HackerNews и вебу.
- **Автоматизация GitHub и сборка пакетов:** создание репозиториев, коммиты, генерация `PKGBUILD` (Arch Linux / AUR) и `CMakeLists.txt` (C++20).
- **Математическое восстановление штрихкодов:** разгадка повреждённых цифр (`??`) алгоритмом Modulo-10/11 и распознавание стран по официальной таблице GS1.
- **Международный планировщик задач и крон:** сохранение расписаний в Cloudflare D1 с автоопределением часовых поясов по языку и городам.

## Быстрый старт

Для запуска нужны всего **3 переменные** — остальное опционально:

```bash
git clone https://github.com/zaryamyn273-crypto/prometheusopenbot.git
cd prometheusopenbot
cp .env.example .env   # TELEGRAM_BOT_TOKEN, ADMIN_ID, ROUTER_API_KEY
pip install -r requirements.txt && python bot.py
# или через Docker: docker compose up -d --build
```

Полные гайды по ключам: [docs/setup/keys.md](docs/setup/keys.md) — деплой: [Railway](docs/setup/railway.md) • [Docker](docs/setup/docker.md)

## Архитектура

Конвейер: апдейт Telegram → гейт-привратники → фоновая архивация в D1 → **триаж Tier 0/1** (часы, болтовня, курсы — без ИИ) → Tier-2 ReAct-агент (до 8 раундов) → перевод и доставка. Память трёхуровневая (L1 RAM → Cloudflare KV → D1 SQL/FTS5); модули инструментов грузятся лениво, только нужные. Пробы: `GET /healthz`. Детали: [docs/architecture/overview.md](docs/architecture/overview.md)

## Полная матрица команд Telegram (Telegram Commands)

Прометей оснащён развитой системой команд. Для устранения конфликтов с другими ботами **в супергруппах команды требуют суффикса `_prometheus` или упоминания бота** (например, `/help_prometheus` или `/del_prometheus 10`). В личных сообщениях (ЛС) стандартные и суффиксные команды работают одинаково.

### 1. Базовые и общие команды
* **`/start`**
  - **Описание:** Персональный запуск бота, приветствие, проверка прав доступа и инициализация сессии.
  - **Доступ:** Для всех пользователей.
* **`/help`**
  - **Описание:** Интерактивное многоязычное руководство по работе с ботом, списку инструментов и правилам групп.
  - **Доступ:** Для всех пользователей.
* **`/tools` (или `/tools_prometheus`)**
  - **Описание:** Вывод каталога подключённых инструментов ИИ (поиск, зрение, финансы, файлы, OSINT и др.).
  - **Доступ:** Для всех пользователей.
* **`/clear` (или `/clear_prometheus`)**
  - **Описание:** Сброс оперативной памяти диалога (RAM) для текущего чата и начало нового разговора без прошлого контекста.
  - **Доступ:** Для всех пользователей.
* **`/id` или `/getid` (или `/id_prometheus`)**
  - **Описание:** Извлечение числового идентификатора (`user_id` / `chat_id`), юзернейма и метаданных отправителя или реплая.
  - **Доступ:** Для всех пользователей.

### 2. Данные в реальном времени, финансы и медиа
* **`/search <запрос>`**
  - **Описание:** Спекулятивный живой поиск по нескольким поисковикам (Tavily AI, Bing, DuckDuckGo) с верифицированным ответом быстрее 1.2 с.
  - **Пример:** `/search последние новости ИИ 2026`
  - **Доступ:** Для всех пользователей.
* **`/crypto [символ]`**
  - **Описание:** Текущие котировки криптовалют (BTC, ETH, USDT, TON, SOL) и суточное изменение в процентах.
  - **Пример:** `/crypto btc` или `/crypto` (сводка ведущих монет).
  - **Доступ:** Для всех пользователей.
* **`/gold`**
  - **Описание:** Сводка цен на золото (слитки, 18K), инвестиционные монеты и мировой спот.
  - **Доступ:** Для всех пользователей.
* **`/weather <город>`**
  - **Описание:** Прогноз погоды, текущая температура, влажность, скорость ветра и метеоусловия любого города.
  - **Пример:** `/weather Москва` или `/weather Berlin`
  - **Доступ:** Для всех пользователей.
* **`/calc <выражение>`**
  - **Описание:** Высокоточный алгебраический калькулятор (тригонометрия, проценты, факториалы) без галлюцинаций LLM.
  - **Пример:** `/calc (500 * 1.20) + sqrt(144)`
  - **Доступ:** Для всех пользователей.
* **`/music <трек / исполнитель>`**
  - **Описание:** Поиск и скачивание аудиозаписей студийного качества 320 кбит/с вместе с синхронизированными субтитрами (.lrc).
  - **Пример:** `/music Hans Zimmer Time`
  - **Доступ:** Для всех пользователей.

### 3. Планировщик задач и крон
* **`/remind <время> <текст>` (или `/schedule`)**
  - **Описание:** Создание напоминания или периодической крон-задачи с сохранением в Cloudflare D1 SQL (устойчиво к перезагрузке сервера).
  - **Примеры:**
    - `/remind 15m Проверить духовку`
    - `/remind завтра в 17:00 по Москве Колл с командой`
    - `/remind at 14:00 London time Team sync`
    - `/remind */30 * * * * Проверка сервера`
  - **Доступ:** Для всех пользователей.
* **`/schedules`**
  - **Описание:** Список всех активных запланированных задач для текущего чата с номерами ID и датой следующего запуска.
  - **Доступ:** Для всех пользователей.
* **`/cancel_schedule <id>`**
  - **Описание:** Отмена запланированной задачи по её числовому номеру (`/cancel_schedule 3`).
  - **Доступ:** Для всех пользователей (создатель задачи или админ).
* **`/timezone <город>` (или `/tz`)**
  - **Описание:** Просмотр или установка часового пояса пользователя (`/tz Europe/Moscow` или `/tz London`).
  - **Доступ:** Для всех пользователей.

### 4. Очистка и массовое удаление сообщений
* **`/del` (в ответ на сообщение)**
  - **Описание:** Моментальное удаление конкретного сообщения, на которое сделан реплай.
  - **Доступ:** Главный администратор и администраторы группы.
* **`/purge <количество>` (или `/del <число>`, `/clean <число>`)**
  - **Описание:** Массовое удаление последних N сообщений бота (от 1 до 100) синхронно в Telegram, Cloudflare D1 и оперативной памяти, с самоуничтожающимся подтверждением через 4 секунды.
  - **Пример:** `/purge 10` (также срабатывает на фразу на естественном языке: «удали 10 последних сообщений»).
  - **Доступ:** Главный администратор и администраторы группы.

### 5. Управление инфраструктурой Railway
* **`/railway status`**
  - **Описание:** Живой телеметрический опрос контейнеров Railway, активных сервисов (`prometheusopenbot`, `9router`) и статуса последнего деплоя (SUCCESS / BUILDING / CRASHED).
  - **Доступ:** Только Главный администратор.
* **`/railway redeploy [сервис]`**
  - **Описание:** Мгновенный перезапуск и пересборка контейнера на Railway по последнему коммиту без захода в веб-панель.
  - **Пример:** `/railway redeploy prometheusopenbot`
  - **Доступ:** Только Главный администратор.
* **`/railway vars [сервис]`**
  - **Описание:** Безопасный просмотр переменных окружения сервиса с маскировкой секретов и паролей.
  - **Доступ:** Только Главный администратор.

### 6. Терминал Linux и облачные песочницы
* **`/sh <команда>` (или `/bash`)**
  - **Описание:** Продвинутый shell сервера с сохранением рабочей директории (`cd`), таймаутом 35 с, преднастроенными токенами окружения и отправкой больших логов (>3500 символов) в виде документа `.log`.
  - **Пример:** `/sh df -h && free -m` или `/sh cd src && ls -la`
  - **Доступ:** Только Главный администратор (деструктивные команды заблокированы намертво).
* **`/e2b <код>`**
  - **Описание:** Изолированное выполнение кода Python или JavaScript в облачных микроконтейнерах E2B без риска для сервера.
  - **Доступ:** Только Главный администратор.
* **`/e2bsh <команда>`**
  - **Описание:** Выполнение bash-команд в изолированной песочнице E2B.
  - **Доступ:** Только Главный администратор.
* **`/e2bstatus`**
  - **Описание:** Проверка подключения и состояния облачного клиента E2B.
  - **Доступ:** Только Главный администратор.
* **`/set_e2b <ключ>`**
  - **Описание:** Установка или смена персонального ключа API E2B в админ-сессии.
  - **Доступ:** Только Главный администратор.
* **`/set_github <токен>`**
  - **Описание:** Установка или смена персонального токена GitHub для создания репозиториев и коммитов.
  - **Доступ:** Только Главный администратор.

### 7. Управление пользователями и квотами
* **`/limit`**
  - **Описание:** Просмотр израсходованной суточной квоты и оставшихся запросов к ИИ (40 по умолчанию, сброс в 00:00 UTC).
  - **Доступ:** Для всех пользователей (у Главного администратора лимит снят).
* **`/setquota <id_пользователя> <лимит>`**
  - **Описание:** Установка индивидуального дневного лимита запросов для конкретного пользователя.
  - **Пример:** `/setquota 123456789 100`
  - **Доступ:** Только Главный администратор.
* **`/resetquota <id_пользователя>`**
  - **Описание:** Мгновенный сброс расхода суточной квоты пользователя к нулю.
  - **Доступ:** Только Главный администратор.
* **`/ban <цель>`**
  - **Описание:** Блокировка пользователя во всех слоях бота и базе D1 по ID, нику или ответу на сообщение.
  - **Доступ:** Только Главный администратор.
* **`/unban <цель>`**
  - **Описание:** Разблокировка пользователя и восстановление доступа.
  - **Доступ:** Только Главный администратор.
* **`/mute` и `/unmute`**
  - **Описание:** Ограничение или возврат права отправки сообщений в группе.
  - **Доступ:** Главный администратор и администраторы группы.
* **`/mutelist`**
  - **Описание:** Список заглушённых участников в текущей группе.
  - **Доступ:** Главный администратор и администраторы группы.

### 8. Управление группами и сетью
* **`/admin` (или `/panel`)**
  - **Описание:** Панель управления ботом: статистика нагрузки, памяти, подключений к D1 и сервисам.
  - **Доступ:** Только Главный администратор.
* **`/groups`**
  - **Описание:** Список всех групп с участием бота и их статус (`active` или `pending`).
  - **Доступ:** Только Главный администратор.
* **`/leave <id_группы>`**
  - **Описание:** Аккуратный и целенаправленный выход бота из группы без потери сохранённой истории.
  - **Доступ:** Только Главный администратор.
* **`/bangroup <id_группы>`**
  - **Описание:** Полная блокировка группы, моментальный выход и запрет повторного добавления.
  - **Доступ:** Только Главный администратор.
* **`/channels`**
  - **Описание:** Список подключённых каналов под управлением бота.
  - **Доступ:** Только Главный администратор.
* **`/net`**
  - **Описание:** Сетевая диагностика доступности глобальных API и сервисов ИИ.
  - **Доступ:** Только Главный администратор.
* **`/remember <ключ> <значение>`**
  - **Описание:** Запись постоянного правила, факта или системного указания в долговременную память (`manage_admin_memory`).
  - **Доступ:** Только Главный администратор.
* **`/forget <ключ>`**
  - **Описание:** Удаление правила или записи из долговременной памяти.
  - **Доступ:** Только Главный администратор.

## Безопасность

- Написанный ИИ код — только E2B-клауд; без ключа — DISABLED, локального запуска нет.
- Секреты маскируются как `[SECRET]`; админ — только числовой `ADMIN_ID`.
- Анти-джейлбрейк в 3 слоя: детерминированный прескан сообщений, блок иммунитета в промпте, гейты админ-инструментов.
- SSRF-защита: fetch только публичных хостов; чтение файлов — только `/tmp`; HTML экранируется.
- Полная модель угроз + responsible disclosure: [SECURITY.md](SECURITY.md)

## Лицензия и участие

Open-source проект: чистая масштабируемая агентная архитектура для сообщества. Баг-репорты и pull request'ы приветствуются.
