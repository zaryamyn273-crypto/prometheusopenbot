## Обзор

**Прометей** — open-source Telegram-бот, который подключает языковую модель к реальным инструментам. Идея простая, и он просто её выполняет:

- **Не гадай — проверь:** всё, чему нужны живые данные (цены, погода, новости, статус сайтов), берётся напрямую из инструментов, а не из памяти модели. Если инструмент недоступен, бот так и говорит. Всё.
- **Ключ нужен не для всего:** обязательны только токен Telegram, ID админа и один OpenAI-совместимый ключ модели. Остальное (Tavily, Cloudflare, GitHub, Spotify, E2B) опционально — без них тоже работает, просто на бесплатных запасных вариантах.
- **В группах не лезет без спроса:** отвечает только при обращении (ответ на сообщение, упоминание или слово «Прометей»). Остальное тихо архивируется.
- **На сервере код не выполняется:** написанный ИИ код выполняется только в облачной песочнице E2B; без ключа инструмент отключён (локального запуска нет по дизайну). Деструктивный shell не выполняется никогда, даже по приказу админа.
- **Не только персидский:** язык определяется по тексту сообщения (а не только по настройкам клиента) — персидский, английский, русский, арабский, турецкий...; выводы инструментов при необходимости переводятся.
- **Честная дневная квота:** каждый пользователь получает `DAILY_USER_LIMIT` (по умолчанию 40) полных ИИ-ответов в сутки во всех чатах; автосброс каждые 24 часа (00:00 UTC) без cron; админ — безлимит и может менять квоту любого (`/setquota`, `/resetquota`). Команда `/limit` показывает остаток.
- **Админу не нужен слеш:** поручения на естественном языке выполняются напрямую («leave group X», список групп, «set quota for X to 100»...) — без угадывания, с живой проверкой.
- **Безопасность групп:** вход — только с одобрения админа (кнопки в ЛС), живой список из Telegram, история сохраняется при выходе, выход — всегда точечный и проверенный.
- **Массовое удаление сообщений (`/purge`, `/del`):** атомарная очистка сообщений бота по команде или естественной фразе («удали 10 последних сообщений») синхронно в Telegram, Cloudflare D1 и оперативной памяти.
- **Управление инфраструктурой Railway (`/railway`):** проверка статуса сервисов, просмотр логов и немедленный редеплой контейнеров без хранения ключей в репозитории.
- **Глубокий OSINT (`osint_person_dossier`):** параллельный сбор цифрового следа и досье по GitHub, Keybase, Telegram, Reddit, HackerNews и вебу.
- **Автоматизация GitHub и сборка пакетов:** создание репозиториев, коммиты, генерация `PKGBUILD` (Arch Linux / AUR) и `CMakeLists.txt` (C++20).
- **Математическое восстановление штрихкодов:** разгадка повреждённых цифр (`??`) алгоритмом Modulo-10/11 и распознавание стран по официальной таблице GS1.
- **Международный планировщик задач и крон:** сохранение расписаний в Cloudflare D1 с автоопределением часовых поясов по языку и городам.

## Быстрый старт

Для запуска нужны всего **3 переменные** — остальное опционально:

```bash
git clone https://github.com/zaryamyn273-crypto/prometheusopenbot.git
cd prometheusopenbot
cp .env.example .env   # TELEGRAM_BOT_TOKEN, ADMIN_ID, ROUTER_API_KEY
pip install -r requirements.txt && python bot.py
# или через Docker: docker compose up -d --build
```

Полные гайды по ключам: [docs/setup/keys.md](docs/setup/keys.md) — деплой: [Railway](docs/setup/railway.md) • [Docker](docs/setup/docker.md)

## Архитектура

Конвейер: апдейт Telegram → гейт-привратники → фоновая архивация в D1 → **триаж Tier 0/1** (часы, болтовня, курсы — без ИИ) → Tier-2 ReAct-агент (до 8 раундов) → перевод и доставка. Память трёхуровневая (L1 RAM → Cloudflare KV → D1 SQL/FTS5); модули инструментов грузятся лениво, только нужные. Пробы: `GET /healthz`. Детали: [docs/architecture/overview.md](docs/architecture/overview.md)

## Инструменты

~**90 инструментов** в 6 семействах (финансы, веб/сеть, медиа, наука, система/админ, GitHub) + облачная память. Полная матрица: [docs/architecture/tooling.md](docs/architecture/tooling.md)

## Безопасность

- Написанный ИИ код — только E2B-клауд; без ключа — DISABLED, локального запуска нет.
- Секреты маскируются как `[SECRET]`; админ — только числовой `ADMIN_ID`.
- Анти-джейлбрейк в 3 слоя: детерминированный прескан сообщений, блок иммунитета в промпте, гейты админ-инструментов.
- SSRF-защита: fetch только публичных хостов; чтение файлов — только `/tmp`; HTML экранируется.
- Полная модель угроз + responsible disclosure: [SECURITY.md](SECURITY.md)
